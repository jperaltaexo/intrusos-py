Maestro de SKU

Sin maestro cargado — los códigos escaneados quedarán como "no identificados".

Se detectan automáticamente: SKU · Descripción · Unidades x Caja (999999 se ignora como "sin definir") · Validación de lote (define si el SKU pide lote y/o vencimiento) · y todas las columnas de códigos (EAN PEYA, OTROS CÓDIGOS, EAN, DUN, blíster…).
Cada código se clasifica por su estructura GS1 (EAN-13, DUN-14, UPC-A, EAN-8), aunque haya varios en la misma celda o estén en columnas cruzadas. Para los DUN se deriva además el EAN-13 equivalente.

Configuración

Las posiciones 100% numéricas deben tener exactamente esta cantidad de dígitos (evita cargar 90600200 cuando es 090600200). Dejalo en 0 para desactivar el control. No aplica a posiciones alfanuméricas.

Generar ASN para Infor

Unifica los exportables de intrusos de todos los relevadores y arma el archivo .xls (Excel 2003) con las 3 pestañas (Data / Detail / Validations), todo en formato texto, listo para que IT lo cargue. Este paso se hace una sola vez, en la compu, al cierre del relevamiento.

Reglas aplicadas: QTYEXPECTED en unidades (bultos × UxB) · PACKKEY desde la columna PACK del maestro · líneas agrupadas por SKU + posición + vencimiento · LOTTABLE02 = DSP · STATUS = 0 · LPN vacío · vencimiento en formato dd/mm/yyyy 08:00 · SUSR4 = "UxB= n" (sin este dato Infor no procesa la línea, por eso las líneas sin UxB se excluyen y se listan).
